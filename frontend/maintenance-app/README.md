# [Maintenance & Operations App](http://localhost:3002)

Aplicación web Angular para el equipo de operaciones y mantenimiento de UrbanMove.
- **Puerto local:** `3002`
- **Tecnología:** Angular + Nginx (Docker)
- **Microservicios conectados:**
  - `inventory-service` (`http://localhost:8001`)
  - `maintenance-service` (`http://localhost:8005`)
  - `relocation-service` (`http://localhost:8006`)
  - `acquisitions-service` (`http://localhost:8007`)
