# UrbanMove - Sistema Distribuido de Movilidad Urbana

## Ejecución local
1. Asegúrate de tener **Docker Desktop** abierto y corriendo.
2. Ejecuta los scripts desde la raíz del proyecto según tu sistema operativo:
   - **Windows:**
      - Arrancar: `.\start.bat` (o doble clic).
      - Parar (conservando datos): `.\stop.bat`
      - Reiniciar de cero (borra volúmenes/datos): `.\reset.bat`
   - **Linux / macOS:** *(dar permisos la primera vez con `chmod +x *.sh`)*
      - Arrancar: `./start.sh`
      - Parar (conservando datos): `./stop.sh`
      - Reiniciar de cero (borra volúmenes/datos): `./reset.sh`
