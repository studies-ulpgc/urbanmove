# UrbanMove - Sistema Distribuido de Movilidad Urbana

## Ejecución local
1. Asegúrate de tener **Docker Desktop** abierto y corriendo.
2. Ejecuta el script correspondiente a tu sistema operativo desde la raíz del proyecto:
    - **Windows:** Haz doble clic en `start.bat` o ejecuta `.\start.bat` en la terminal.
    - **Linux / macOS:** Ejecuta `chmod +x start.sh && ./start.sh`.
